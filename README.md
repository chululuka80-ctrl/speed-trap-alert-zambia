# Speed Trap Alert Zambia

A starter Progressive Web App (PWA) prototype.

## Features
- GPS speed display in km/h (where the device/browser provides speed data)
- User-set speed reminder
- Save local community reports for speed checks, checkpoints, hazards and accidents
- Nearby alert when a saved report is within approximately 300 metres
- Installable PWA shell and basic offline caching

## Important limitations
- This prototype does not contain an official speed-camera database.
- Reports are stored only on the current phone/browser; they are not shared between users.
- Reports are user-submitted and unverified.
- GPS accuracy and speed availability vary. Follow road signs and local law.
- Use only when safely parked; do not handle the phone while driving.

## Publish with GitHub Pages
1. Upload all files in this folder to the root of your GitHub repository.
2. Open repository Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the provided HTTPS URL.
6. On Android Chrome, open the URL → menu ⋮ → Add to Home screen / Install app.
